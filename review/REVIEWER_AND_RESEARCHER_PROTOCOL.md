# Researcher / reviewer protocol

## Roles

**Researcher:** reconstructs sources, states a target, commits methods/gates, and produces the candidate claim.

**Adversarial reviewer (Devil's Audit):** attacks prior-art subtraction, hidden assumptions, baseline weakness, scope promotion, register laundering, and unfalsifiable rescue routes.

**Reconstruction reviewer:** receives a jargon-reduced/source-removed presentation and tests whether the useful distinctions can be recovered without founder rescue.

**Release reviewer:** verifies source packages, licenses, citations, hashes, build reproducibility, visible OPEN/WITHHOLDs, and target-platform requirements.

## Separation rule

Where a result depends on non-preauthored return, the claim-generating path may not inspect the hidden adjudication before commitment. A later verifier-only repair is admissible only if proposal, target, threshold, learner answer, and evaluator return stay fixed. EDU15R1 is the current canonical example.

## Reviewer output

Every material objection should be typed as one of: fatal inconsistency; unsupported promotion; missing comparator/prior art; ambiguous register/index; reproducibility defect; didactic/founder-dependence defect; provenance/licensing defect; bounded weakness; stylistic suggestion. Only the first seven can block release.

## Inhabitable review

For public-facing claims, the reconstruction reviewer should ask:

1. What reaches the indexed center or affected system?
2. What local condition/orientation determines how it is received?
3. What continuation is selected or enacted?
4. What consequence can return without being pre-authored by the proposal?
5. What maintenance cost is paid, and by whom?
6. Can another center disagree, refuse, fork, or exit without becoming merely an error term?
7. What remains stable enough to learn, and what remains reopenable enough to be corrected?

Failure here does not refute a theorem. It can block a public explanation, governance claim, or human-facing deployment when the omitted relation is materially part of what is being claimed.
