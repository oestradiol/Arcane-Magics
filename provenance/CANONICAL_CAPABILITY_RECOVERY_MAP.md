## Rule

Do not reimplement an earned capability until its Canonical realization has been classified as non-transplantable into the current Git carrier.

The relevant distinction is:

```text
same kernel code
!= same VM state
!= same TransformProgram
!= same research state
!= same return path
!= same executable developmental organism
```

A historical harness result is donor evidence. A restart-persistent state object is stronger. A current Git descendant is stronger still only when the old causal function is actually executable.
