## 2. Explicit `C_project` deletion tests

### D1 — remove source/exposure provenance

Counterfactual:
two claims have identical content, but one is independently generated and one is derivative/self-produced.

Without provenance:
the states collapse.

With provenance:
historical credit, independence grade, evidence weight and contamination audit can differ.

Result: **decision difference present**.

### D2 — remove independently authoring Other centers

Counterfactual:
a local model's own generated output and an independently authored participant return have the same surface content.

Without independent-author condition:
both can count as external correction.

With it:
only the latter can supply the relevant alterity claim.

Result: **evidence-classification difference present**.

### D3 — remove participant/source jurisdiction

Counterfactual:
an actor/model is capable of producing a recommendation but lacks authority over the Human/source/register.

Without jurisdiction:
capability can silently become authorization.

With it:
action may be blocked, narrowed, routed for consent/review, or remain interpretive only.

Result: **admissibility difference present**.

### D4 — remove claim-relative non-preauthored return

Counterfactual:
a test outcome is structurally entailed by the same model used to generate the test route.

Without non-preauthorship:
self-conditioned confirmation can be counted as independent evidence.

With it:
the result is downgraded or treated as implementation validation only.

Result: **warrant difference present**.

### D5 — remove retention changing later admissibility

Counterfactual:
two systems have identical immediate response but only one records the consequential return and changes later policy/state.

Without retention:
they are treated as equivalent.

With retention:
future actions differ.

Result: **diachronic decision difference present**.

### D6 — remove recursive sufficiency

Counterfactual:
representation `Q` is sufficient for current action selection, but an action chosen using `Q` makes an erased variable consequential.

Without recursive sufficiency:
`Q` remains accepted.

With it:
`Q` must be enriched, narrowed, or rejected for the future intervention horizon.

Result: **formal/local decision difference present**.

### D7 — remove dependency-local failure propagation

Counterfactual:
a physical bridge from semantic relation R to physical P fails.

Without dependency locality:
either the semantic relation is globally erased or the failed bridge is ignored.

With dependency locality:
only bridge dependents narrow; independently licensed native objects remain.

Result: **failure-routing difference present**.

### D8 — remove RegisterBridge loss/nonidentity/warrant fields

Counterfactual:
two representations preserve one structural invariant but differ in omitted semantics, authority and source history.

Without explicit loss/nonidentity/warrant transform:
same-relation can silently become same-object/same-authority/same-warrant.

With it:
translation can be accepted structurally while stronger target claims remain blocked.

Result: **cross-grammar transport difference present**.

## 6. What would reverse the S11 `C_project` result?

Any of the following is sufficient to narrow it:

1. a mature framework is found that substitutes the full tested composition at the same index with no decision difference;
2. formalization shows one or more conjuncts are derivable/redundant under the others;
3. prospective deployment finds that tracking a conjunct never changes action/warrant/reconstruction within the declared task;
4. the integration cannot be transmitted without founder-specific interpretation;
5. the bridge fields add documentation burden without changing any admissible consequence.

S11 therefore does not close the integration permanently. It makes its current value **falsifiable by substitution**.
