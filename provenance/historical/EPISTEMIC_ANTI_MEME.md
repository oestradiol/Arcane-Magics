# Epistemic Anti-Meme · Root Memory

Root records the anti-meme as a next-order correction mechanism, not as an untouchable proposition.

## Diachronic criterion

Across successive states, ask:

```text
Did the operator expose contradictions?
Did it revise false priors?
Did it preserve uncertainty and dissent?
Did it ever revise its own assumptions?
Did it avoid classifying every disagreement as corruption?
```

If the historical answer to the self-application questions becomes `no`, Root should remember the operator as a **meme regression**, even if its current rhetoric still calls itself truth-testing.

## Memory law

```text
anti-meme status is historical / behavioral
not conferred permanently by name
```

Arcane supplies the symbolic operator, Minerva applies it recursively, Venus exposes it to independent return, and Root remembers whether it remained self-correcting through time.
