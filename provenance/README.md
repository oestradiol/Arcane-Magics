# Provenance

This directory contains historical states that remain reconstructible without remaining live authority.

The GitHub repository preserves the immediate predecessor, `oestradiol/Research` at commit `9c9b8f0eaf311dd6191b7c66079404df8b2a846f`, as a nested Git tree under `provenance/research-v1.5/tree/`. That snapshot includes the Structured Unity Framework, the earlier knowledge atlas, governance machinery, validation tools, release metadata, and the root history that preceded the Venus–Minerva reorganization.

The predecessor snapshot is evidence of development, not a second current canon. Its historical licenses continue to govern its files. Moving a file into provenance does not upgrade, revoke, or replace its earlier license or epistemic status.

Old Venus is handled differently. The exact archive remains in the private research store because its history may contain material unsuitable for automatic public export. Public archaeology contains only regression cases and structural summaries that survived the privacy and relevance audit.

Frozen Version-0 manuscript source is also retained privately where publication-source text contains project-local trajectory aliases. Public documentation may cite or describe those artifacts without republishing private-source material.
