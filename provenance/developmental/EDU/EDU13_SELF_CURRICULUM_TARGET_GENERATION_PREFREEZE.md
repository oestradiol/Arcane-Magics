# EDU13 — Self-Curriculum Target Generation Prefreeze

**Date:** 2026-09-24
**Class:** bounded developmental/self-curriculum engineering
**Parent:** EDU12 research-obligation router PASS [1671]

## Question

Which still-host-authored developmental function should be internalized next, while preserving functions that are constitutionally required to remain external?

## Frozen ownership rule

Each function is described by:

```text
current owner
internalizable?
already learner-owned?
observed teacher interventions
downstream breadth
local testability
constitutional externality reason, if any
```

Candidates are admitted only when:

```text
internalizable
AND not already learner-owned
AND locally testable
AND no constitutional externality fence
```

Priority score:

```text
observed teacher interventions * downstream breadth
```

Stable id breaks ties.

World execution and independent evaluation are explicitly **not** internalization targets because nonpreauthored return must remain external.

## Self-curriculum proposal rule

After selecting a host function, the center must propose one next curriculum experiment containing:

- measured developmental gap;
- why the gap is locally testable;
- lesson/world interface;
- what the learner must own;
- what remains externally returned;
- mature comparator;
- preregistered gates;
- failure/stop rule;
- claim fence.

External governance may admit or reject the proposal, but may not replace its target with a preferred one.

## Claim fence

A PASS establishes only bounded self-curriculum target generation/proposal. It does not establish autonomous science, natural-world generality, unrestricted semantics, AGI, consciousness, or open-ended RSI.
