# Provenance model

The project separates several historical coordinates that are often lazily collapsed into “came from.”

```text
PROJECT_ORIGIN
HISTORICAL_PRIORITY
EXPOSURE
LATER_CONSTRAINT
COMPARATIVE_CONVERGENCE
FORMAL_INHERITANCE
PUBLICATION_FREEZE
```

These are not interchangeable.

The current project's endogenous origin is tracked separately from older intellectual/developmental strata. Historical resemblance does not prove exposure; exposure does not prove formal inheritance; publication priority does not rewrite project origin.

Public provenance records only distinctions needed for public reconstruction. Exact private developmental history remains controlled provenance unless its release is independently justified.
