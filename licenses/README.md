# Licensing map

This repository intentionally uses two default grants.

- **Theory, monographs, documentation, research notes, vocabulary maps, and other project-owned knowledge:** CC BY-NC-SA 4.0.
- **Project-owned software:** PolyForm Noncommercial 1.0.0.
- **Commercial use:** requires a separate written grant from the relevant rightsholder.
- **Capability-sensitive operational release:** is a separate governance decision; copyright is not treated as a safety mechanism.

This is **source-available/noncommercial software**, not OSI Open Source. Do not describe the software license as "open source".

Historical material that was actually distributed under an earlier license keeps whatever rights were granted in that distribution. Merely finding an old internal `LICENSE` file does not prove a public grant occurred. Third-party quotations, bibliographic metadata, trademarks, standards, datasets, and other external material keep their own legal status.

## Verification notes

The copied license texts were checked against the canonical Creative Commons and PolyForm Project pages on 2026-09-24. CC BY-NC-SA 4.0 permits sharing and adaptation with attribution, noncommercial use, and ShareAlike; PolyForm Noncommercial 1.0.0 permits noncommercial use, modification, and redistribution subject to its notice and other terms. The repository intentionally does **not** call PolyForm-licensed code OSI Open Source.

If an earlier artifact was actually distributed under a prior license (for example an older CC BY release), that historical grant remains attached to that distributed version. This successor policy does not attempt to claw it back. New project-owned successor material uses the file-scoped policy stated here.

## arXiv

As of 2026-09-24, arXiv explicitly offers **CC BY-NC-SA 4.0** as a selectable article license, alongside CC BY, CC BY-SA, CC BY-NC-ND, the arXiv perpetual non-exclusive license, and CC0. arXiv licenses are irrevocable for the posted version. The project can therefore select CC BY-NC-SA 4.0 for an arXiv version when the submitter controls the necessary rights. See `docs/ARXIV_RELEASE_GUIDE.md`.

This file states project policy and release engineering, not jurisdiction-specific legal advice.
