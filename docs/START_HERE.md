# Start Here · OFE

OFE is the **science / future** layer.

## One sentence

**OFE keeps only distinctions that can still matter to an admitted family of future observations, decisions, or consequences.**

## Core relation

```text
x ~_F y  iff  Future_F(x) = Future_F(y)
Q_F = S / ~_F
```
