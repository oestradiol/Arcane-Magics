# OFE Scientific Future

## Role

OFE receives a model of the current Self↔World boundary from Venus and asks what future evidence can still distinguish its unresolved states.

```text
Venus model
→ declare future family F
→ derive / compute operational equivalence
→ test candidate distinctions
→ retain Residual or quotient gauge
→ reopen when F expands
```

## Scientific criterion

A distinction is scientifically consequential at scope `F` only when some admitted future test, observation, intervention, or decision can separate the candidate states.

## Externality

OFE does not manufacture the future it evaluates. Simulations and predictions may define tests or expectations, but they are not automatically independent returned evidence.

```text
prediction != return
simulation != World
formal discriminability != observed difference
```

## Exit to Root

Only a typed scientific consequence is handed to Root through `handoff/ofe-to-root/*`, where it can revise the routing map without erasing which layer earned it.
