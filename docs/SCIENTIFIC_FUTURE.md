# Venus Scientific Future

## Temporal contract

Root supplies the best current map. Venus supplies the controlled opening through which that map can fail.

```text
Past Religion
→ Root Now Map
→ Venus hypothesis / experiment
→ World / Other return
→ Root successor memory
```

## Admission contract

A candidate entering Venus must state:

1. originating branch/register;
2. current Self/provenance dependency;
3. open bridge or test family;
4. what counts as independent return;
5. discriminator;
6. expected failure consequence;
7. whether result is CONSUME / WITHHOLD / REOPEN.

## Externality requires Self provenance

```text
Other
= what can still return consequence not already authored by the relevant Self closure
```

This is relational, not absolute. A source may be external to one closure and internal to a larger one, so provenance and jurisdiction must remain explicit.

## Future does not preexist as verdict

Venus may predict, simulate, and preregister. None of those objects counts as returned future consequence until an admitted independent channel supplies it.

```text
prediction != return
simulation != World
candidate success != promotion
```
