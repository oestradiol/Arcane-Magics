# Venus Epistemic Anti-Virus Gate

Venus tests whether a claimed anti-meme is actually corrigible under the Scientific Future.

## Gate

A candidate correction operator passes only if it can survive an adversarial family containing at least:

- evidence against its protected propositions;
- evidence against its own thresholds or classification rules;
- disagreement from independently sourced centers;
- null cases where no revision is warranted;
- cases where the operator itself should be weakened or discarded.

```text
anti-meme candidate
→ preregister self-application test
→ independent return
→ if self-exemption detected: FAIL / mind-virus risk
→ if uncertainty preserved and false prior consumed: retain provisionally
```

## Noncollapse

```text
recursive criticism != universal skepticism
revision capacity != forced belief change
sacred vocabulary != evidence
CI pass != independent return
```

The decisive question is not whether the operator attacks other beliefs. It is whether returned consequence can still attack the operator itself.
