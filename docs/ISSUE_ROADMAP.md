# Issue Roadmap

This is a reader-facing projection of the live execution plan. GitHub issues remain the authoritative work items.

## Scheduling law

Sort work lexicographically by:

```text
1. composable learning leverage
2. ease / time-to-information
3. resource leverage
```

Interpretation:

- a task that can confirm, kill, reduce, or unlock many downstream claims outranks a merely convenient task;
- among similarly high-leverage tasks, prefer the shortest path to a discriminating external return;
- use resource/product/funding leverage as the tie-breaker, not as scientific warrant.

Prestige is not a scheduling dependency.
