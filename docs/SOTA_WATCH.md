## Watch triggers

Recheck an entry when:

- a benchmark version changes;
- the benchmark saturates;
- a new leader materially moves the cost-performance frontier;
- contamination or evaluator defects are reported;
- a new system class appears;
- a result directly overlaps a Venus residual;
- a benchmark's task distribution no longer represents the target claim.
