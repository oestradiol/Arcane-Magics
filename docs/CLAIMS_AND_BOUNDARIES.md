# Claims and boundaries

Venus × Minerva distinguishes at least the following claim/register families where consequential:

- `REL/STRUCT` — structural relation;
- `EPI` — epistemic/warrant claim;
- `ONT` — explicit model-ontological articulation;
- `FORM` — formal/mathematical claim;
- `EMP` — empirical/scientific claim;
- `PHEN` — phenomenological occurrence/structure;
- `THEO` — theological/ultimate-orientation interpretation;
- `NORM` — normative/governance claim;
- `HIST` — historical/provenance claim;
- `ENG` — implementation/engineering claim.

A statement can occupy multiple registers, but warrant does not automatically transfer among them.

## Common forbidden promotions

```text
phenomenal occurrence -/-> external source attribution
symbolic fit -/-> mechanism identity
formal consistency -/-> empirical truth
successful model -/-> ontological identity
historical recurrence -/-> direct inheritance
centrality -/-> truth sovereignty
implementation success -/-> authorization
```

## Native-object non-annihilation

Failure to establish a stronger bridge does not erase an object independently licensed at a weaker/native register. Conversely, the native object's legitimacy does not repair the failed stronger bridge.
