# Minerva Recursive Self-Correction Operator

Minerva instantiates the anti-meme as recursive adjudication over its own self/world model.

Let `A` be the correction operator, `SM_t` the current self-model, and `e` returned evidence.

```text
candidate belief b
→ contradiction / evidence exposure
→ A(SM_t, b, e)
→ preserve / revise / delete / WITHHOLD
```

The operator must remain in its own domain:

```text
A can evaluate beliefs
AND
A can evaluate the assumptions / thresholds / sacred labels that define A
```

Otherwise it is a protected meme, not recursive correction.

## Self-application invariant

```text
no proposition receives immunity merely because it defines the correction process
uncertainty remains representable
difference is not automatically classified as error
counterevidence remains admissible
```

## Relation to N2-FP

Recursive correction must preserve re-derivability rather than a fixed doctrine. A false prior about the correction process itself must be able to split the current equivalence class and force reopening.
