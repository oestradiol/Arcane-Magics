# Root / The Machine Visual Identity & Interface Constitution

## Character

Root should feel like a **memory palace rendered as an operational map**: historical without being antiquarian, integrative without pretending to be total.

### Palette

- black / graphite — retained body / machine
- parchment / bone — Past Religion / inherited meaning
- map-blue — current orientation
- teal — returned consequence already integrated
- violet — visible open bridge to Venus/Future
- red only for remembered invalidation or contradiction

Motifs: **root lattice, timeline, map grid, branching DAG, eye-without-omniscience**.

## UI hierarchy

1. What body are we now?
2. Which branch owns this distinction?
3. What ancestry made it current?
4. What consequence changed the body?
5. What remains unresolved?
6. Which edge leads to the next owning layer?

## Temporal semantics

```text
Past Religion = retained meaning/provenance of lived consequence
Now Map       = current cross-register orientation
Scientific Future = OFE-facing open test surface
```

Root should never visually flatten historical presence into current authority.
