# Venus Visual Identity & Interface Constitution

Venus should feel like a **two-sided model boundary**: one face turned toward reconstructible Self, one toward irreducible World/Other.

- graphite — self-provenance
- cyan/teal — returned relation
- violet — unresolved Other / open bridge
- amber — WITHHOLD
- white — explicit model boundary

Motif: **♀ / mirrored aperture / porous membrane**.

UI order:

1. current Self closure;
2. provenance;
3. World/Other model;
4. boundary permeability;
5. unresolved Residual;
6. outgoing handoff to OFE.

Never render the model as the territory.
