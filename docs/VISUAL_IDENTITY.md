# Eclipsis Visual Identity & Interface Constitution

## Character

Eclipsis should feel like a **faceted observatory**: geometric, spacious, explicit about what is visible from which face.

### Palette

- deep indigo — `#312E81`
- bridge violet — `#7C3AED`
- horizon slate — `#475569`
- returned-consequence teal — `#0F766E`
- background / void — near-black where supported

Motifs: **◇**, facets, dashed arrows `⇢ / ↛ / \dashrightarrow`, indexed centers.

## UI hierarchy

1. local object / index;
2. boundary;
3. neighboring face or register;
4. bridge status;
5. preserved invariant;
6. information lost;
7. discriminator;
8. failure consequence.

Never render an OPEN bridge visually like an established pipeline.

## Visual semantics

- solid arrow = established transformation within the declared model;
- dashed arrow = OPEN bridge;
- boxed equation = central structural compression;
- gray status = WITHHOLD;
- violet = physics-facing hypothesis;
- teal = independently returned consequence.
