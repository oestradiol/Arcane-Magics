# Venus Visual Identity & Interface Constitution

## Character

Venus should feel like a **future-facing scientific horizon instrument**: sparse, cold, permeable, and explicit about uncertainty.

### Palette

- near-black / deep slate — current boundary
- cyan / teal — returned consequence
- spectral violet — OPEN bridge / unclosed hypothesis
- white — explicit future-test surface
- amber only for WITHHOLD
- red only for actual discriminator failure

Motif: **♀ / horizon aperture / open boundary**.

## UI hierarchy

1. current Self/provenance boundary;
2. admitted candidate;
3. future-test family;
4. open bridge;
5. independent return source;
6. discriminator;
7. Residual;
8. CONSUME / WITHHOLD / REOPEN;
9. handoff back to Root memory.

## Visual semantics

```text
solid arrow  = established transformation inside current model
dashed arrow = OPEN bridge
teal         = returned consequence
violet       = hypothesis / future-facing bridge
amber        = WITHHOLD
```

Never render a prediction as if it were a return.
