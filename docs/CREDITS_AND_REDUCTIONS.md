# Credits, genealogy, reductions, and residual contribution

**Status:** live methodology / repository governance  
**Date:** 2026-09-24

Venus-Minerva keeps five questions separate:

```text
project causal derivation
!= historical priority
!= comparative recurrence
!= technical realization
!= residual contribution
```

This distinction is inherited from the project genealogy and reduction methodology preserved in the historical Canonical/Past lineage and the S10-S11 residual-contribution work.

## 1. Credit is not a scalar

When a mature predecessor or contemporary comparator is found, classify the relation before changing any claim.

| Relation | Meaning |
|---|---|
| **PROJECT_GENEALOGY** | this object was causally developed inside the documented Venus lineage |
| **HISTORICAL_PREDECESSOR** | an older source contains a relevant idea or construction |
| **INDEPENDENT_REDISCOVERY** | Venus reached a related construction without that source being a documented causal input |
| **COMPARATIVE_RECURRENCE** | similar structure appears elsewhere, without establishing inheritance or identity |
| **TECHNICAL_DONOR** | external machinery was actually imported or adapted |
| **MATURE_COMPARATOR** | an established system is strong enough to substitute in an adversarial test |
| **SUBSUMES_AT_T** | at task/index T, the comparator preserves every declared consequential distinction |
| **RESIDUAL_AT_T** | at task/index T, deleting the Venus relation and substituting the comparator changes a declared consequence |

A source can occupy more than one row, but no row silently implies another.

Historical priority deserves credit. It does not become retroactive causal ancestry.

Independent rediscovery deserves accurate genealogy. It does not erase earlier scholarship.

## 2. Reduction is indexed

For task/index `T`, comparator set `C`, and project relation `r`:

```text
Subsumed_T(r | C)
iff
  remove r
  + substitute mature comparator machinery C
  -> no relevant change in
     admissible action,
     prediction,
     authorization,
     evidence classification,
     reconstruction,
     transport,
     later admissibility,
     correction route,
     or failure localization.
```

If a relevant consequence changes, `r` retains **residual contribution at T**.

A reduction therefore retires only the claim that was actually substituted. It does not erase:

- project causal genealogy;
- the fact that a machine independently developed the construction;
- a bounded causal or developmental result already demonstrated;
- neighboring registers that have independent warrant;
- stronger residuals not covered by the substitution.

## 3. What mature comparison may change

A mature comparison may lawfully:

- narrow a novelty claim;
- replace a project-local mechanism name with established terminology;
- consume a redundant scaffold as gauge;
- identify a stronger baseline;
- split a broad object into subsumed and residual components;
- reopen an evaluation target.

It may not, without separate evidence:

- rewrite the project's causal history;
- relabel an independent project trajectory as inherited;
- erase an engineering milestone because the idea has intellectual neighbors;
- convert "similar" into "same";
- convert "historically preceded" into "functionally subsumed";
- convert "subsumed at one task" into "globally unnecessary".

## 4. SOTA watch is not a genealogy engine

The SOTA watch asks:

> What is the strongest current external system against which this live Venus claim should be tested?

It does **not** ask:

> Which current system should receive retroactive authorship of Venus?

New SOTA changes the comparator surface and may change what Venus still needs to demonstrate. It changes credit only when actual historical or technical dependence is established.

## 5. Advertising rule

Public communication should state the strongest true positive contribution first, followed immediately by its scope.

Good:

> Venus has demonstrated a bounded developmental lineage in which curriculum targeting, problem selection, preregistration, evidence routing, and World-feed policy progressively moved into learner-owned state while World execution and independent evaluation remained external.

Then:

> This does not yet establish capability-SOTA, AGI, open-ended RSI, or autonomous science.

Bad:

> Venus is not AGI, not SOTA, not autonomous science, not... [three pages later] ...but something happened.

Claim fences prevent lying. They are not an instruction to hide earned value.

## 6. Reduction result vocabulary

Prefer:

- `HISTORICALLY_PRECEDED`
- `INDEPENDENT_REDISCOVERY`
- `SUBSUMED_DESCRIPTIVELY`
- `SUBSUMED_AT_T`
- `RESIDUAL_CONTRIBUTION_AT_T`
- `INTEGRATION_RESIDUAL`
- `MATURE_REDUCTION`
- `OPEN`
- `WITHHOLD`

Avoid using `PRIOR_ART` as a catch-all. Patent-style language is too coarse for the project's separate questions of genealogy, precedence, substitution, and residual contribution.
