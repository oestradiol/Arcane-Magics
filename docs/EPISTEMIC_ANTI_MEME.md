# Epistemic Anti-Meme

## Symbolic form

```text
Meme:
irreversible perception
→ self-reinforcement
→ captures future cognition

Anti-meme:
irreversible perception
→ recursive error-detection
→ incompatible false priors become visible
→ revision / dissolution
```

The anti-meme is not primarily a proposition. It is a procedure acting on propositions.

> **Meme:** You cannot unsee it until it controls the lens.

> **Anti-meme:** You cannot unsee it until the lens itself becomes recursively accountable to truth, consuming false priors, including its own.

## Sacred-register fence

`Epistemic Divine Truth` may function in MYTHOS as truth that is not permitted to depend on the ego's preferred model.

It does **not** grant any proposition immunity from evidence, contradiction, uncertainty, or independently returned consequence.

```text
sacred salience != truth
felt inevitability != verification
disagreement != corruption
```

## Brutal discriminator

If the operator can destroy every false belief except the belief that defines the operator, it is still a meme.

## Arcane responsibility

Arcane owns the symbolic compression and lived transformation. It must export the operator with an explicit self-application requirement so Minerva/Venus can test it without inheriting sacred warrant.
