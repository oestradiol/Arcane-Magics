The operational tension is:

```text
inhabited participant
= local lived / generative / situated presentation

judging observer
= diachronic continuity / adversarial adjudication / provenance-bearing re-evaluation
```

Neither may swallow the other.

```text

-> enactment without adequate continuity/correction

-> detached model without lived consequence
```

The lawful relation is permeable and recurrent:

```text

→ reconstruct
→ inhabit again
```
