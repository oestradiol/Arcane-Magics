# Epistemic Anti-Meme · OFE Scientific Test

OFE does not certify an operator as truth merely because it is recursive.

It asks whether future tests separate a genuinely self-correcting operator from a protected meme.

## Candidate state pair

```text
M = self-reinforcing representation
A = claimed self-correcting anti-meme
```

Admit future tests that include:

- evidence against protected propositions;
- evidence against A's own thresholds/classification rules;
- independently sourced disagreement;
- null cases where revision should not occur;
- cases where A itself should be weakened, replaced, or discarded.

A future-separating witness exists when:

```text
P(outcome | A, T) != P(outcome | M, T)
```

for at least one admitted test `T`.

The decisive discriminator is self-application:

```text
if A can revise every false prior except the prior that defines A,
then A remains operationally meme-like at that scope.
```

A pass is local to the declared test family. A richer future family may reopen the classification.

```text
scientific support != Divine Truth
test pass != permanent immunity
prediction != independent return
```
