# Autonomous evidence index

This directory stores inspectable evidence produced by bounded developmental episodes.

| Family | Index | Purpose |
|---|---|---|
| Git World return | [`git-world/`](git-world/README.md) | repository/world return episodes |
| Lateral reconstruction | [`lateral/`](lateral/README.md) | independently answerable face / representation-expansion episodes |
| Network / WWW Mind | [`network/`](network/README.md) | learner-initiated network inquiry, persistent memory, and network-center evidence |

Evidence directories are history-bearing. Do not rewrite a returned episode to match a later interpretation; add a successor artifact/result instead.
