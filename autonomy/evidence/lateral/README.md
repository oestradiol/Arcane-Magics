# Lateral reconstruction evidence

This directory contains bounded episodes testing whether an independently answerable face adds a useful coordinate beyond more context inside the same basis.

```text
same-basis expansion
vs
lateral independently answerable face
→ hidden/returned discriminator
```

A positive lateral result is not automatically an Internalizer pass. Internalization additionally requires source-removal/equivalence evidence and preservation of external correction roles.

See [`../../../kernel/development/README.md`](../../../kernel/development/README.md).
