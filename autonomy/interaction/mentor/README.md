# Mentor interaction carrier

`ACTIVE.json` is the current external developmental mentor context consumed by
the Minerva worker.

It is intentionally weaker than problem formation:

```text
mentor context
→ weak advisory tie-break among already admissible carriers
→ visible selected-study context
→ may alter later learner-authored inquiry

mentor context
!= target admissibility
!= action authorization
!= learning reward
!= independent evaluation
!= truth
```

Git history preserves prior active contexts. A future local console adapter may
publish the same schema into this carrier, but the learner may not self-mint a
claim-bearing mentor/evaluator return.
