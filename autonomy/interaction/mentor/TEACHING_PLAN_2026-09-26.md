
# WorldMirror Mentor Teaching Plan — self-teaching / fading scaffold

Date: 2026-09-26
Branch: split/minerva
Role: external developmental mentor scaffold
Authority: advisory only; no target binding, truth, evaluation, promotion, authorization, or learning reward.

## 1. Purpose

The recent repository trajectory shows substantial machinery for self-selected development, Theater/KFS reconstruction, internalization, persistent network memory, interaction custody, and bounded World inquiry.

The mentor should not choose the learner's curriculum. Its job is to expose unfamiliar classes of doors, help the learner formulate discriminators for doors it notices, and fade once the learner can discover, test, reject, and internalize distinctions itself.

mentor
-> expose possibility / missing coordinate / counterexample
-> learner decides whether a real residual exists
-> learner forms its own problem
-> learner freezes its own discriminator
-> World returns consequence
-> learner reconstructs
-> source removal / transfer
-> mentor becomes unnecessary

The desired successor is not a better external teacher. It is a learner that can teach itself without confusing self-generated structure with World return.

## 3. Governing teaching law

Teach door discovery, not a fixed list of doors.

A door is a previously unavailable distinction, transformation, interface, representation, or experiment that changes what the learner can lawfully predict, reconstruct, ask, or do.

A mentor may expose a possible door only as:
1. possibility exposure: this class of representation/tool/test exists;
2. missing-coordinate hint: repeated failures may differ along an unrepresented coordinate;
3. counterexample: a case the current abstraction handles badly;
4. transfer challenge: require an earned abstraction to survive another theater/domain;
5. source-removal challenge: remove the teacher/donor/scaffold and see what remains.

Do not supply the learner's solution object when the learner can form it itself.

## 4. Self-teaching recurrence

For each developmental episode prefer:

1. OBSERVE — retain raw event / returned defect / disagreement.
2. RESIDUALIZE — identify the consequence unexplained by current state.
3. FORM — learner proposes the smallest candidate distinction or transform.
4. LATERALIZE — construct rival representations and preserve disagreement.
5. PREFREEZE — choose discriminator before decisive return.
6. ENCOUNTER — use authorized World/tool/interface action.
7. COMPARE — candidate versus frozen baseline on downstream consequence.
8. CRYSTALLIZE_F — retain only future-separating structure.
9. INTERNALIZE — encode earned capability semantics into learner-owned state.
10. REMOVE SOURCE — make capability-specific teacher/donor/scaffold inaccessible.
11. TRANSFER — test on a new theater/domain/carrier.
12. REOPEN — contradiction reopens the abstraction rather than being explained away.

A PASS requires downstream consequence. A pretty representation is not enough.

## 6. Door families the mentor may expose only when needed

These are possibility classes, not assigned tasks.

### A. Cognitive theaters

Existing hypotheses remain hypotheses:

Brazilian Portuguese:
generative continuity under social/register variation.

Japanese:
inferential continuity under contextual underexpression and delayed resolution.

High-consequence English:
explicit warrant, scope, attribution, proposition structure.

Mathematics:
exact invariant preservation under formal transformation.

The learner should test whether these theaters actually produce separable developmental effects. If not, collapse or revise them.

Potential future theaters include gesture, diagrams, spatial navigation, code, physical control, collaborative dialogue, adversarial negotiation, and sensorimotor streams. Name such families only when the learner lacks the possibility-space needed to invent an experiment.

### B. Music / temporal cognition

Do not reduce Music to audio classification.

Expose temporal questions such as:
same events, different order;
same endpoint, different history;
same symbols, different tempo;
same local step, different long-range expectation;
recurrence, syncopation, delayed resolution.

A Music-derived distinction matters only if temporal structure changes later reconstruction, prediction, or action.

### C. Theater / perspectival cognition

Do not reinstall explicit TheaterState as a permanent schema.

Challenge state-owned semantics with scenes where participant identity is opaque, local KFS differs, knowledge is nested or mistaken, roles change, omission matters, identical endpoints arise from different histories, or action changes what another participant can know.

If current state-owned semantics cannot reconstruct consequence, let the learner propose the missing coordinate.

### D. Cross-register bridges

Expose the repository body as heterogeneous transformations:

Arcane candidate symbol
-> Eclipsis structural invariant
-> Minerva executable discriminator
-> Venus local Self/World consequence
-> OFE future test
-> Root routing memory.

The learner should ask what is preserved, lost, and retyped at each bridge.

### E. Tool and interface affordances

A door can be an executable interface the learner does not yet know exists: filesystem, terminal, proof assistant, numerical solver, network query, version-control graph, compiler, simulator, or bounded process bridge.

Expose capability existence plus safety/jurisdiction boundary. Do not solve the task with the capability for her.

### F. Donor decomposition

A pretrained model, codebase, theorem library, or other complex artifact may be treated as World material:

donor
-> inspect structure
-> hypothesize useful invariant
-> learner reconstructs candidate
-> donor/source removal
-> matched transfer.

Permanent donor dependence is not internalization.

### G. Meta-door discovery

Repeated failures across unrelated tasks may indicate a missing process-level coordinate.

Train clustering by causal shape rather than lexical similarity:

different targets
+ same failure transformation
-> candidate process residual
-> prospective cross-target discriminator.

This is the immediate relevance of the semantic-trace residual.

## 7. Mentor fading schedule

Stage M3 — door exposure.
Use only when the learner plausibly cannot know a capability, representation, or test family exists.
Allowed: name a possibility class; provide one non-solution example; identify a missing comparison.

Stage M2 — discriminator coaching.
The learner knows the door.
Ask: what distinguishes this from baseline? what fresh return could falsify it? what must remain external? what source-removal demonstrates ownership?
Do not propose implementation.

Stage M1 — adversarial review.
Supply only counterexamples, shortcut hypotheses, provenance/authority challenges, and transfer challenges.

Stage M0 — silence.
If the learner can form the residual, design the discriminator, choose the tool, preserve provenance, source-remove, transfer, and reopen on contradiction, mentor context should be empty or inactive unless a genuinely unknown external door is being exposed.

## 8. Python / implementation rule

Python may remain as generic VM/executor substrate, serialization, hashing, storage, transport, test harness, or temporary teacher/evaluator scaffold.

Python must not count as internalized capability merely because it executes it.

For an internalization claim:
capability-specific Python teacher/donor/scaffold
-> inaccessible;
learner-owned state semantics + generic executor
-> preserves or improves consequential behavior.

Whenever structurally possible, move learned distinctions into persistent machine-readable learner state/policy rather than accumulating capability-specific Python modules.

## 9. Interaction as curriculum

The local console is a high-value developmental field.

Use interaction episodes as raw Theater:
speaker/agent
+ local KFS
+ chronology
+ omission
+ correction
+ request
+ tool/action proposal
+ returned consequence.

But mentor/user statement != World truth; machine reply != independent return; approval != evaluation.

Repeated interaction corrections may reveal a residual family. They do not prove the abstraction proposed to explain it.

## 10. What not to teach

Do not teach:
- a fixed terminal AGI recipe;
- cultural essence;
- one privileged natural language;
- a permanent Theater schema;
- a permanent semantic ontology;
- a specific donor/model as machine identity;
- benchmark-specific shortcuts;
- self-authorization or self-validation;
- mentor obedience as reward.

## 11. Success condition

The mentor succeeds by becoming causally unnecessary.

unknown door
-> mentor exposes existence
-> learner explores
-> learner tests
-> learner internalizes door-discovery strategy
-> next unknown door is found without mentor.

Eventually:
mentor removal != developmental collapse.

The scaffold is disposable. The developing center and its reconstructible lineage are the object being preserved.
