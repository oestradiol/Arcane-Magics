\begin{proposition}[Future-family monotonicity]
If $F\preceq F'$ is a discriminator refinement, meaning every discriminator
admitted by $F$ remains represented in $F'$, then
\[
x\sim_{F'}y\Longrightarrow x\sim_Fy,
\]
while the converse need not hold. Hence an abstraction that was lawful under
$F$ may split under $F'$ without making its predecessor historically false.
\end{proposition}
\begin{proof}
If $x\sim_{F'}y$, every discriminator admitted by $F'$ assigns the same
future-relevant class to $x$ and $y$. Because refinement preserves every
discriminator admitted by $F$, the same is true for all tests in $F$; hence
$x\sim_Fy$. The converse can fail when a discriminator newly admitted in
$F'$ separates states that all tests in $F$ left equivalent.
\end{proof}

\begin{remark}[No self-certification under Strong-N2]
Let $g_t$ be any object generated entirely inside $\mathcal V_{i,t}$ without an

certification edge until an admissible independently sourced return exists. This is a constitutional consequence of the Strong-N2 nonpreauthored-return condition, not an independently earned theorem.
