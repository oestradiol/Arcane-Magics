# Internal O* causal reconstruction

This branch adds a learner-side, name-free reconstruction of the non-sovereign
Self<->World relation and makes that reconstruction causally upstream of bounded
routing decisions.

It deliberately keeps two objects separate:

```text
external O* / CTL
= non-waivable structural admission and correction boundary

internal O*
= learner-side reconstructed relation that may alter what Venus chooses
```

The internal object is reconstructed from returned episodes, not copied from the
strings `O*`, `Strong-N2`, `Intelligent Love`, `Venus`, `Minerva` or
`non-sovereignty`.

Current neutral factors:

```text
independently reachable external incidence
correction permeability
reachable revision of the implicated dependency
status/carrier non-sovereignty unless carrier differences are consequence-relevant
```

The first causal test compares the same routing context under:
- intact reconstructed internal relation;
- no internal relation in the decision path;
- counterfactually corrupted internal relation.

A PASS here is only a bounded causal-routing result. It is not a phenomenal
consciousness claim, AGI claim, sovereignty claim, or open-ended RSI claim.
