## Boot

```bash
python -m kernel.runtime.current
```

Boot verifies and hydrates the exact IG10 VMK2 state from a compact hot checkpoint plus two content-addressed cold payloads. It does not replay the 118.8 MB trajectory on every run.

## State layers

Git source and admitted kernel state are Venus-Minerva authority. Canonical remains donor/research/provenance material until explicitly admitted here.

## Scaffold internalization and recurrent correction

`runtime/internalizer.py` makes the R193 distinction executable:

```text
internalize scaffold mediation
!=
internalize World / return / evaluator / authority
```

A capability can receive a bounded internalization receipt only when source provenance is preserved, the original scaffold can be made inaccessible while behavior remains equivalent, a successor can reconstruct the function, and fresh World return remains external. The kernel rejects attempts to consume evidence identity, evaluator independence, trust roots, authorization, jurisdiction, claim-binding authority, STOP/WITHHOLD law, or rollback/parent custody as local capability.

The same module exposes an O* transition-contract validator for the Strong-N2 noncollapses. It checks that correction/reopening and nonpreauthored return remain reachable, provenance remains reconstructible, self-revision does not become self-authorization/self-validation, and static state equality or self-sealing are not treated as the developmental fixed point.

These are governance semantics. A passing receipt does not itself prove a capability improvement, authorize promotion, or establish Safe Strong RSI.
