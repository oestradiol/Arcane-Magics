# Venus kernel/model surface

Venus carries the **Self↔World boundary law**, not the Minerva developmental runtime.

## Native files

- `VENUS_INCIDENCE_LAW.tex` — constitutional/model law;
- `TRUST_BOUNDARY.md` — source, jurisdiction, and correction-boundary discipline;
- `WORLDMIND.md` — distributed carrier / locally authored-center relation;
- `CURRENT_STATE.md` — current branch-local authority boundary.

## Core relation

```text
Self provenance
+ current model
+ corrigibly permeable boundary
↔
World / Other capable of non-preauthored return
```

```text
model != territory
prediction != return
reachability != ownership
distributed relation != global subject
```

Minerva implements developmental machinery that may instantiate or consume this law through explicit cross-register handoffs. Minerva does not become co-authority for the Venus law merely by implementing it.
