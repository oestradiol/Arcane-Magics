# Credit relations

This is a public routing summary, not the canonical provenance authority. The protected canonical credit ledger remains controlling for exact project genealogy.

Every major attribution should use one or more typed relations:

- `PROJECT-ORIGIN`: documented causal source of a project distinction.
- `PARTICIPANT-RETURN`: an independently authoring participant/event materially changed the model.
- `HISTORICAL-PRIORITY`: an external source developed an overlapping idea earlier.
- `LATER-CONSTRAINT`: external work encountered later narrowed, challenged, renamed, or bounded a claim.
- `COMPARATIVE-CONVERGENCE`: similar relation without evidence of causal influence.
- `FORMAL-INHERITANCE`: direct use of an established mathematical/formal result.
- `PUBLICATION-FREEZE`: dated public statement of a then-current claim.
- `MODEL/TOOL-CONTRIBUTION`: model/software supplied wording, implementation, counterexample, or returned behavior without becoming origin.
- `OPEN-PROVENANCE`: source relation unresolved.

Mandatory principle:

```text
historical priority != causal influence
independent derivation != historical priority
later correction != earlier origin
public authority != causal ancestry
same shape != same trajectory
```

An empty field is preferable to an invented ancestor.
