# Operator genealogy

This file tracks recurrence of relations across sources without collapsing recurrence into identity or causal ancestry.

A valid entry records:

```text
source object
→ term-free relation
→ project comparison object
→ preserved invariant
→ information loss
→ credit type
→ residual / OPEN
```

Examples:

- [**Heidegger**](../comparisons/HEIDEGGER.md) → situated being-in-world → local world presentation → preserves situated disclosure; loses project provenance/jurisdiction calculus.
- [**Simondon**](../comparisons/SIMONDON.md) → individuation from preindividual field → differentiation before completed relata → preserves individuation; does not solve the project's first-differentiation bridge.
- [**Peirce/Pattee**](../comparisons/PEIRCE_PATTEE.md) → sign interpretation/control → consequential semantic transport → preserves symbol/dynamics consequence; does not supply participant jurisdiction.
- [**Whitehead/Dewey**](../comparisons/WHITEHEAD_DEWEY.md) → process/action alters successor conditions → retained consequence → strongly subtracts general process novelty.
- [**Levinas / participatory sense-making**](../comparisons/LEVINAS_PARTICIPATORY_LONGINO.md) → differentiated other / interaction autonomy → `Other != model(Other)` and higher-order interaction without merged authorship.
- [**RGM**](RGM_OPERATOR_ARCHAEOLOGY.md) → cross-register claim governance, inference costs, term removal, anti-self-sealing, formal-authority limits, non-collapse of other centers → historical project-internal precursor to several current governance/bridge relations. Primary-source availability is now closed; exact operator transmission/formal inheritance remains claim-specific OPEN.

External comparative recurrence and project-internal ancestry are different provenance relations. RGM is therefore not placed in the external-thinker list merely because it precedes current work.

For project-causal derivation, use [Credit relations](../credit/CREDIT_RELATIONS.md) and the protected canonical provenance authority rather than inferring ancestry from this comparative table.
