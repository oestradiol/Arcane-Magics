# Projection, section, reconstruction

For `p : X → Y`, a section `s : Y → X`, when it exists, satisfies `p(s(y)) = y`.

The project keeps four non-entailments explicit: projection does not guarantee a section; a section need not be unique; existence does not imply cheap reconstruction; the same projection does not identify the same source trajectory.

This family coordinates observer reconstruction, compression, compiler artifacts, root reconstruction, and the P-vs-NP witness projection while preserving their different domain assumptions.
