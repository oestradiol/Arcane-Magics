# Executed fences

A declared caution is not automatically an operative epistemic control.

```text
declared caution -/-> effective corrigibility
textual disclaimer -/-> enforced non-collapse
```

A fence is stronger when a schema, type boundary, transition rule, validator, authorization gate, receipt, negative control, or counterfactual test detects or prevents the forbidden promotion.

This distinction is a major cross-strata historical lesson: sophisticated disclaimers can coexist with a runtime architecture that still assimilates every return into the preferred model.
