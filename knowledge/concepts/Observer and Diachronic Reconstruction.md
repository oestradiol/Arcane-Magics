# Observer and diachronic reconstruction

The Observer is modeled as diachronic continuity reconstructed across successive Perspective states and retained provenance, not as one stored sovereign object.

```text
Observer_{i,≤t}
→ Perspective_{i,t}
→ action / return
→ retention + provenance
→ Observer_{i,≤t+1}
```

The frontier asks what invariants and reconstruction laws make this more than relabeling ordinary history.
