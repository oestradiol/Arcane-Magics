# Reference bank

The reference bank stores sources used by the manuscripts, Canonical comparison work, and S0–S11 subtraction program. The `bib/` directory is partitioned by comparison function so a reader can inspect why a source family is present without treating the bibliography as one undifferentiated authority list.

No monolithic `references.bib` is currently tracked. Tooling may generate one later from the partitioned files, but the generated export would remain derivative.

Use:

- [`INDEX.md`](INDEX.md) for source families;
- [`CANONICAL_SOURCE_MAP.md`](CANONICAL_SOURCE_MAP.md) for why selected sources matter to current comparisons;
- [`../evidence/HUMANITY_EVIDENCE_ATLAS.md`](../evidence/HUMANITY_EVIDENCE_ATLAS.md) for the subtraction surface;
- [`../credit/CREDIT_RELATIONS.md`](../credit/CREDIT_RELATIONS.md) for attribution types.

References can supply historical priority, formal inheritance, later constraint, comparison, or empirical support. Citation alone does not make a source project origin or transfer warrant between registers.
