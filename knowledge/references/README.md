# Reference bank

The reference bank combines manuscript bibliographies with sources added during Canonical development. Obvious duplicate records are removed by DOI or normalized title.

`bib/` partitions entries by comparison function for browsing. A generated monolithic `references.bib` export is planned for tooling that prefers one BibTeX file; it is **not currently tracked in this repository**.

`CANONICAL_SOURCE_MAP.md` records why selected sources appear in current comparison. It is a comparison/provenance map, not a scalar support score.

References constrain, compare, or support specific project relations. They do not become retroactive project origin or transfer warrant across registers merely by citation.
