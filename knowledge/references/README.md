# Reference bank

The reference bank merges the active Arcane and CBRD Version 0 bibliographies, removes obvious duplicate records by DOI or normalized title, and adds explicit sources needed by the current post-V0 Canonical.

`bib/` partitions the 71 entries by comparison function for repository browsing. `CANONICAL_SOURCE_MAP.md` records why named sources appear in the current theory. It is a comparison/provenance map, not a scalar support score.

The earlier governed RGM reference bank remains available in the frozen Research predecessor tree. Its historical claim wording does not inherit current Canonical status.

`INDEX.md` groups the bank by comparison function so Obsidian browsing does not collapse into a flat BibTeX dump.
