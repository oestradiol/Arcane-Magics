# Reference bank

The reference bank combines the current manuscript bibliographies with sources added during Canonical development. Obvious duplicate records are removed by DOI or normalized title.

`bib/` partitions the entries by comparison function for browsing. `references.bib` is the monolithic export for tooling that prefers one BibTeX file.

`CANONICAL_SOURCE_MAP.md` records why selected sources appear in the current theory. It is a comparison and provenance map, not a scalar support score.

`INDEX.md` groups the bank by research function so graph browsing does not collapse into a flat bibliography dump.
