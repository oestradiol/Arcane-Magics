# Heidegger: situated being before a project term

## Source-side problem

Heidegger's *Being and Time* does not begin with an isolated spectator that later acquires a relation to a world. Dasein is already being-in-the-world; practical involvement and disclosed significance precede a picture of a detached subject inspecting external objects.

That historical object deserves reconstruction in its own terms before any project mapping.

## Term-free overlap

Venus × Minerva also rejects the picture in which a complete world is first given from nowhere and a local observer is added afterward.

Overlap:

```text
situated inhabitation
+ local disclosure
+ world not first encountered as detached proposition-list
```

## Nonidentity

```text
Dasein != PerspectiveCenter
being-in-the-world != Perspectivalization Π
Heideggerian disclosure != project provenance calculus
```

The project additionally distinguishes a history-bearing center from the indexed presentation relation, makes participant/source jurisdiction explicit, and asks how returned consequence revises later models and actions.
