## 2. Historical / conceptual atlas

### H1 — relation, process, individuation, becoming

Major predecessor pressure:
- Whitehead: antecedent world -> local concrescence -> achieved actuality -> successor data.
- Dewey: doing/undergoing -> consequence -> reconstruction -> changed future action.
- Simondon: metastable/preindividual field -> transduction -> individuation + milieu -> retained potential.
- Peirce: recursive semiosis and consequence-sensitive inquiry.
- Maturana/Varela and enaction: autonomous organization in recurrent coupling.
- Barad, James, Bergson and related sources: different routes into relation/process/cut/open becoming.

S11 disposition:
`process`, `becoming`, `feedback`, `relation-before-completed-object`, and ordinary action-return are not residual contributions by themselves.

### H2 — model, perspective, warrant and underdetermination

Major predecessor pressure:
- Sellars: presentation does not self-authorize unrestricted ontology.
- van Fraassen: empirical/model adequacy does not force literal acceptance of full theoretical ontology.
- Duhem–Quine: failed prediction does not automatically localize which premise failed.
- Giere / Massimi: situated/perspectival modelling with cross-perspectival constraint.
- Kuhn / Lakatos / Laudan / Feyerabend / Popper: framework change, programme governance, risky criticism and non-sovereign method.

S11 disposition:
`model != Reality`, fallibilism, perspectival modelling and criticism are mature terrain. Project value must be in higher-resolution composition and executable routing.

### H3 — alterity, participant autonomy and higher-order organization

Major predecessor/control pressure:
- Levinas: strong anti-assimilation pressure at ethical/interpersonal index.
- participatory sense-making: partially autonomous interaction without erasing participant autonomy.
- Longino: differentiated agents + public criticism + uptake + standards.
- distributed cognition / group agency / collective intentionality / polycentric governance.
- S8 accepted constraint:
  `higher-order functional organization != unitary phenomenal subject != automatic authority over constituent Humans`;
  `distributed cognition != distributed authorization`.

S11 disposition:
participant non-substitution remains a live constitutional guard, but not a historically isolated insight.

### H4 — provenance, derivation and history-bearing state

Mature technical controls:
- W3C PROV: entities, activities, agents, responsibility, derivation, time, alternate/specialized descriptions and provenance interchange.
- event sourcing: persistent event sequence, state reconstruction, temporal query, replay and alternative-history computation.
- version-control/review systems: explicit revision history and gated state transition.

S11 disposition:
generic provenance/history is strongly subsumed. Residual contribution can only arise when provenance changes **warrant, jurisdiction, later admissibility, or correction routing**.

### H5 — grammar, views, bidirectional transport and anti-grammar

Mature technical controls:
- bidirectional transformation / lens literature: `get : S -> V`, `put : S -> V -> S`, information omitted from a view, and round-trip laws.
- formal representation/equivalence traditions more broadly: multiple realizations can preserve declared behavior without being identical.

Project-local anti-grammar line:
```text
controlled transformations
-> invariance / sensitivity
-> induced relational state R_T
-> operational equivalence class
-> writable consequence
-> cross-frame transport
-> commutation/composition/path residual
```

S11 disposition:
basic source<->view transport and round-trip discipline are not project-specific. The higher-resolution candidate is the coupling of transport with **warrant transform, jurisdiction, provenance loss, nonidentity, failure dependency closure and register non-annihilation**.
