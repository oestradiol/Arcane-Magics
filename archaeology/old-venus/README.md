# Old Venus archaeology

Old Venus is preserved as evidence, not revived as architecture.

The raw archive contains hundreds of commits and a large amount of abandoned, duplicated, experimental, and self-contradictory machinery. Copying that crate graph into the successor system would preserve precisely the wrong thing.

This public archaeology keeps three classes of residue:

1. **surviving operators** whose distinction still matters;
2. **historical implementations** that are useful comparison fossils;
3. **failures** strong enough to become regression tests.

Selected source is retained only when a concrete historical implementation is necessary to understand a surviving distinction or regression. Historical source keeps its historical license and is not the implementation base.

Useful lineages include residual/WITHHOLD semantics, prediction→receipt→assimilation, provenance, jurisdiction, compiler obligations, projection-relative stability, open-world return, and source-removal/correction tests.

Large historical nouns such as Root, Brain, universal Form, sovereign closure, and fixed-point Self do not migrate merely because they once had code.
