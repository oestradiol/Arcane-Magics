# Frozen Version 0 paper sources

The unified private workspace retains the exact Arcane and CBRD Version 0 source bundles as frozen provenance. They are not included in the public export because historical source text contains project-local identity aliases unnecessary for reconstructing the current public theory.

This is a privacy boundary, not a claim that the manuscripts never existed. Their source lineage remains in the private workspace. A later public paper projection should be compiled from the then-current public Canon and independently reviewed rather than silently rewriting Version 0.

Version 0 remains **not evidence of Version 1**. Publication artifacts are projections from research state, not the authority root.
