\section{Negative-result record}

A reusable negative record should include:
\begin{enumerate}
\item tested claim and exact realization;
\item frame, register, index, and jurisdiction;
\item assumptions and dependency bridges;
\item executable or evidential chain;
\item returned result;
\item scoped interpretation;
\item dependency closure and prohibited updates;
\item conditions for reproduction, narrowing, or reopening.
\end{enumerate}

\section{Publication and correction policy}

Frozen predecessor manuscripts remain immutable provenance. This successor source is a working manuscript, not a published release merely because it resides in a public repository. A public version is earned only when a deliberate release freezes the exact source and citation state. Later correction should modify the smallest dependency closure justified by returned consequence.
