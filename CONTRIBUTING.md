# Contributing to Venus

Venus is the **Scientific Future / World↔Self boundary** layer.

## High-value contributions

- sharper future-test families;
- independent-return channels;
- source-independence audits;
- falsifiers for OPEN bridges;
- Residual definitions that separate previously conflated states;
- experiments that force CONSUME / WITHHOLD / REOPEN;
- self-provenance repairs that improve Other/Self typing;
- evidence that a proposed distinction is gauge and can be safely removed.

## Every cross-register contribution must state

1. source layer and source commit;
2. relevant Self/provenance boundary;
3. target future family;
4. what counts as independent return;
5. discriminator;
6. expected failure consequence;
7. claim register;
8. whether the result should be remembered by Root.

## Integration

Do not merge long-lived specialized branches directly. Use the target-based crystallization handoff defined in `docs/CROSS_REGISTER_HANDOFF.md`.

```text
candidate != evidence
execution != verification
prediction != return
CI pass != Root promotion
```
