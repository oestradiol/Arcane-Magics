# Contributing

Issues, counterexamples, reproducibility reports, source corrections, and proposed tests are welcome. A proposal does not become Canon merely because it is merged into a repository branch.

Code or prose contributions to the licensing-sensitive core are not accepted for commercial relicensing by implication. Until a reviewed contributor relicensing agreement is adopted, maintainers should keep such contributions outside the commercially licensable core, request an explicit rights grant before merge, or decline the patch while preserving the issue/test as returned consequence.

Every merged contribution must preserve source attribution and identify copied third-party material.

Technical contributions should identify the failure they address, the scope they change, and a test or reconstruction path when feasible. Build success alone is not evidence that a semantic or scientific claim is true.
