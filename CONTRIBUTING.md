# Contributing to Eclipsis

This branch is for **structural models and explicitly burdened bridges**.

## High-value contributions

- formalize local-view / gluing structure;
- identify false equivalences across faces/registers;
- sharpen meta-qualia definitions;
- supply consciousness comparators;
- define explicit LQG / GQT bridge maps;
- derive observables for horizon Residual claims;
- attack the PPD-Crystal construction;
- compare cosmological projections with FLRW/LQC/GFT alternatives;
- demonstrate that a proposed bridge is gauge or reducible;
- improve source genealogy.

## Every bridge contribution must state

1. source register;
2. destination register;
3. preserved invariant;
4. lost information;
5. mechanism, if any;
6. comparator;
7. discriminator;
8. what failure deletes.

## Do not

- promote symmetry into identity;
- call an OPEN bridge a theorem;
- borrow OFE proof status;
- borrow Venus engineering success;
- borrow Arcane meaning as mechanism evidence.
