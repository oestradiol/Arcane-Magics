# Contributing to Venus

Venus is the **Self & World / model** layer.

High-value contributions include:

- repairs to Self/World provenance;
- clearer boundary typing;
- tests that distinguish self-authored recurrence from independent return;
- model structures that preserve unresolved Residuals;
- attacks on false Self/Other boundaries;
- corrections to Monograph V/kernel correspondence.

Cross-register work enters through `handoff/minerva-to-venus/*` and leaves through `handoff/venus-to-ofe/*`.
