# Regression ledger

These are failure classes future implementations and publications should make difficult to reproduce silently.

## Evidence and verification

- a claim inserts itself into its own evidence graph and thereby passes connectivity;
- supposedly live evidence is a hard-coded fixture;
- unknown/unverifiable state is counted as verified;
- source multiplicity is treated as independent correction;
- representation/hash integrity is treated as semantic validity;
- proof-object existence is treated as proof discharge;
- build success or compilation success is treated as epistemic promotion;
- detector output is narrated as execution;
- local tests are promoted into trajectory-level corrigibility.

## Authority and action

- authorization occurs after irreversible action;
- model/world disagreement is resolved by rewriting the world toward the model;
- influence/prediction is treated as authorship or consent;
- successful lowering is treated as authorization;
- execution is treated as self-verifying.

## Projection and reconstruction

- projection-relative fixed points are treated as observer-independent identity;
- identity/metadata-only perturbations are counted as adversarial transformations;
- definitions make the desired leakage/invariance result true by construction;
- trace persistence is treated as regenerative access;
- same quotient representation with divergent later behavior is treated as recursively sufficient;
- a section/inverse is assumed merely because a projection exists;
- section existence is treated as unique or cheap reconstruction;
- a reconstructed root-like residue is treated as evidence that it generated the differentiated realization.

## Causality and semantics

- ambiguous causal return is discarded rather than retained as residual;
- lexical/statistical similarity is treated as semantic identity;
- linguistic causal labels are treated as causal identification;
- symbolic or phenomenological correspondence is treated as mechanism identity.

## Corrigibility

- a local persistence/protective constraint acquires global jurisdiction and disables criticism, mutation, refusal, fork, exit, or correction;
- representational persistence survives while regenerative access dies (`Cryo`);
- a textual disclaimer is counted as a working epistemic fence without an enforcing transition/check;
- stated uncertainty coexists with an architecture that assimilates every rival route into the preferred conclusion.

## Publication and provenance

- a clean checked-out tree is treated as proof that reachable public Git history is sanitized;
- private provenance preservation is treated as requiring public publication of the whole predecessor DAG;
- an internal snapshot/build is described as a published paper version;
- a historical license is silently generalized to material never actually distributed under it.

## Regression execution status

This ledger is currently **prose-level specification**. The executable regression harness described in the architecture is not yet implemented. A future regression case must identify the exact failure, fixture, expected result, and evidence needed to close it.
