# Responsible release

Publication and capability release are different decisions.

The project aims to make definitions, evidence, formal obligations, negative results, interfaces, and criticism broadly reconstructible. It does not treat that goal as an obligation to publish every operational lowering at the same time.

A component receives additional review when release materially increases the ability to produce irreversible or high-leverage external effects. Review asks what capability becomes easier, whether that capability is necessary to reproduce the claim, whether a lower-capability implementation preserves the epistemic value, what jurisdiction and authorization assumptions are required, and what misuse becomes materially easier because of release itself.

Outcomes may include `release`, `release with reduced capability`, `withhold pending safeguards`, or `do not release at current scope`.

This is release governance, not a claim that licensing controls bad actors after information is public.
