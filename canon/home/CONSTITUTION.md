# Constitution

The project keeps the following distinctions live because collapsing them has repeatedly changed decisions or produced false closure:

```text
model != Reality
coherence != truth
representation != jurisdiction
capability != authority
authority != legitimacy
feedback != independent correction
self-reference != self-validation
same endpoint != same trajectory
same shape != same object
proposal != authorization != execution != verification
```

The strongest earned mid-level relation is:

```text
consequential difference
→ crosses a provisional boundary
→ is transformed, discriminated, or retained
→ changes later admissibility or transformation
```

Three ternary coordinates are separate:

```text
Developmental: |V> |Δ> |T>
Warrant:       LICENSE(P) | LICENSE(not-P) | UNDETERMINED
Governance:    ADMIT | WITHHOLD | REJECT/CUT
```

`UNDETERMINED` is not a third truth value. Governance `WITHHOLD` is not an epistemic truth status. `|V>` is not a runtime enum variant.

A healthy CUT remains corrigible. A representation may be canonical without being a natural kind. A local center may be central to its own perspective without becoming the whole.
