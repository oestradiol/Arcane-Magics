# Public HOME

`canon/home/` is the compact public projection of supported, reconstructible, constitutional, and release-relevant state. It is not an immutable truth database and it is not a copy of the complete private Canonical corpus.

Readers who do not already know the project vocabulary should begin with the [problem-first knowledge bank](../../knowledge/INDEX.md). The constitutional route is:

1. [CONSTITUTION.md](CONSTITUTION.md)
2. [PUBLIC_ONTOLOGY.md](PUBLIC_ONTOLOGY.md)
3. [PROJECTION_MODEL.md](PROJECTION_MODEL.md)
4. [AUTHORITY_AND_LEGITIMACY.md](AUTHORITY_AND_LEGITIMACY.md)
5. [OPERATION_AND_VERIFICATION.md](OPERATION_AND_VERIFICATION.md)
6. [Research Frontier](../frontier/RESEARCH_FRONTIER.md)

A public compression is acceptable only when omitted distinctions are irrelevant to the consequences the public artifact is expected to support. If omission changes interpretation, warrant, jurisdiction, reconstruction, or future admissibility, the projection is too lossy.

For the comparative evidence and novelty-subtraction layer behind the public vocabulary, see [S0–S11 evidence archaeology](../../knowledge/evidence/S0-S11_EVIDENCE_ARCHAEOLOGY.md).
