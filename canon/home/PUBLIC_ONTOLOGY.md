# Public ontology / model projection

This file presents the current public structural model at a level intended to be independently reconstructible without private personal-source material. It does not claim that every modeled relation is a Reality-level primitive.

## Strongest earned mid-level relation

```text
consequential difference
→ crosses a provisional boundary
→ is transformed / discriminated / retained
→ changes later admissibility or transformation
```

Lawful projections at different scales include learning, memory, history, identity, agency, relationship, cognition, governance, and institutional coordination. Recurrence of the relation does not identify those projections as the same object.

## Root frontier

```text
vacuous_relation --δ?--> |Δ> --σ?--> |T> --β--> local Boolean predicates
```

`δ`, the first nontrivial consequential differentiation, remains OPEN. Boolean or three-valued proposition logic begins after enough differentiation exists to form propositions. Runtime software therefore begins post-differentiation and cannot prove the root by instantiating a type.

## Perspective and World

A **PerspectiveCenter** is an inhabited, history-bearing local center. **Perspectivalization** `Π_i` is the indexed presentation/differentiation relation through which a World becomes locally available.

```text
PerspectiveCenter != Perspectivalization
Perspective != pipe
local World != exhaustive Reality
```

A diachronic **Observer** is reconstructed through retained provenance across successive Perspective states rather than stored as one sovereign object.

```text
Observer_{i,≤t} / World_t
→ Π_{i,t}
→ local presentation / PerspectiveCenter_{i,t}
→ phenomenology / model
→ judgment / authorship / enactment
→ World_{t+1}
→ returned consequence
→ retention + provenance
→ Observer_{i,≤t+1}
```

## Semantic Centers

```text
local center ∈ whole
local center != whole
SemanticCenter != TruthSovereign
```

A stable attractor found under a declared projection is projection-relative unless invariance under relevant projection changes is independently established:

```text
Attractor(X | Π_a) may differ from Attractor(X | Π_b)
projection-relative stability != diachronic identity
projection-relative stability != privileged root
```

## HOME / FRONTIER

```text
HOME_isness
= immediate inhabited participation

HOME_operational
= returnability + continuity + memory + reconstruction

FRONTIER_ontology
= explicit mediated corrigible articulation/model

FRONTIER_operational
= independently consequential novelty / contradiction / correction
```

Their recursive dependency can be rendered:

```text
retained HOME_t
→ conditions present inhabitation and prior model
HOME_isness_t
↔ interpretation / retained model
→ FRONTIER_ontology_t
→ probe / enactment
→ FRONTIER_operational(return_t)
→ HOME_operational(retain/reconstruct_t)
→ HOME_{t+1}
```

This is a functional/dependency cycle, not a mandatory micro-temporal order.

## Mind, embodiment, and higher-order organization

Public working type:

```text
Mind = epistemic / inferential / compressive organization
```

Embodied, subconscious, generative, affective, contextual, and protective organization may interact with explicit/conscious/inferential organization. Their interaction can instantiate HOME/FRONTIER functions differently across contexts. No permanent anatomical identity is asserted.

Higher-order cognition, group regulation, or distributed organization does not by itself create one unitary phenomenal subject or authority over constituent Humans.

## Authorship

Authorship is indexed and consequence-bearing:

```text
Perspective_i + retained history
→ selection / judgment
→ enactment
→ returned consequence not fully preauthored by local model
→ revised admissibility
```

The source coordinate matters whenever source substitution can change consequence. Influence, prediction, causal effect, intimacy, centrality, or successful modelling do not transfer another participant's authorship.

## Regenerative retention

A retained trace is not automatically living memory. `RegenerativeAccess` asks whether retained consequence can still participate in admissible reconstruction, judgment, action, criticism, mutation, or transmission.

```text
representation persists
+ correction / mutation / reconstruction channels CUT
→ transmission may survive while generative Spirit dies
```

This is the semantic-poisoning / Cryo failure family.

## Compiler and bridges

`Grammar` is an indexed encoding. `AntiGrammar_T` is a consequential invariant/equivalence class under a declared transformation family `T`. `RegisterBridge` is governed transport between typed registers/objects with explicit loss, nonidentity, provenance, jurisdiction, warrant, and failure closure.

The **Compiler** is broader:

```text
surface
→ parse / refer / type
→ differentiate
→ obligations
→ candidate plan
→ invariant / loss / jurisdiction checks
→ target lowering
```

Authorization, execution, receipt, verification, and write-back remain downstream and non-identical.

## Projection / section / reconstruction

For `p : X → Y`, a section `s : Y → X`, when it exists, satisfies `p(s(y)) = y`.

The project uses this family across observer reconstruction, compression, compiler artifacts, root reconstruction, and complexity-theory witness projections, while keeping target-domain assumptions separate.

A reconstructed root-like invariant may motivate hypotheses; it does not prove that the reconstructed object generated the differentiated realization.
