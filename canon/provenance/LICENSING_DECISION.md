# Venus × Minerva licensing decision — 2026-09-01

**Status:** `CONTROLLING SUCCESSOR GOVERNANCE DECISION / PUBLIC-SAFE`

The project resolves the previous “knowledge public, commercial rights personal” ambiguity in favor of public noncommercial reconstruction with separately granted commercial rights.

```text
new theory / Canon / documentation / knowledge
  -> CC BY-NC-SA 4.0

new software
  -> PolyForm Noncommercial 1.0.0

commercial use of copyright held by the project
  -> separate written permission

capability-sensitive operational release
  -> separate governance decision
```

Historical artifacts retain their historical licenses. No successor policy revokes permissions already granted to an existing copy. The exact V0 manuscript sources remain frozen provenance; selected Old Venus code remains under its historical AGPL terms; legacy Knowledge material already released under CC BY 4.0 retains CC BY 4.0.

The project deliberately does not draft a bespoke “no evil” or field-of-use copyright license. Such a document would create legal ambiguity while doing little to control actors who ignore licenses. Release governance, capability separation, privacy gates, and provenance remain independent controls.

For contributions, provenance-only certification is insufficient where the project intends to retain commercial relicensing ability. A licensing-sensitive merged contribution requires an explicit relicensing grant or another reviewed rights arrangement.

No default warranty, service commitment, exclusivity, or third-party intellectual-property indemnity is granted. Those terms exist only when a signed commercial agreement says they do.

This file states project policy, not jurisdiction-specific legal advice.
