# Post-archaeology retype

Old Venus was not treated as a predecessor architecture to modernize. It was treated as returned historical and engineering consequence against the Canon.

That pass changed the Canon itself:

```text
pre-archaeology Canon
→ Old Venus archaeology
→ returned failures and surviving operators
→ successor Canon
→ archaeology retyped under successor Canon
```

The main status changes were:

- Compiler became a strict first-class formal frontier object.
- projection/section/reconstruction became an explicit cross-cutting calculus.
- the root↔epistemic hinge was demoted unless it adds a discriminator.
- typed status, scoped negative results, governance withholding, and center/presentation nonidentity moved from broad conceptual questions toward exact-calculus questions because historical executable failures already demonstrate why the distinctions matter.

The earlier archaeological record remains history. It is not rewritten to look as if the successor Canon had always existed.
