# Public schemas

These JSON Schemas are **contract-level public specifications**, not proof that a runtime currently persists or validates these objects. They exist so future code and external implementations have a common structural target.

- `claim-record.schema.json` — typed proposition/claim with register, frame, source and warrant.
- `research-event.schema.json` — append-oriented consequence/provenance event.
- `decision-receipt.schema.json` — governance/authorization/execution/verification receipt family.
- `projection-manifest.schema.json` — declared projection, loss and reconstruction obligations.

Schema-valid data may still be semantically false, scientifically unsupported, illegitimate, or operationally unsafe. Syntax is not sovereignty.
